# Superstore ETL and Data Analysis Pipeline

## Project Overview

This project aims to build an end-to-end ETL pipeline using the Superstore sales dataset. Python and Pandas will be used to explore, clean, and transform the data before loading it into a relational database for SQL analysis.

## Dataset Source

[Kaggle - Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

## Project Phases

* **Phase 1:** Data acquisition and extraction.
* **Phase 2:** Exploratory Data Analysis (EDA).
* **Phase 3:** Data cleaning and transformation.

## Tools

* Python
* Pandas
* NumPy
* Matplotlib
* SQL
* GitHub
